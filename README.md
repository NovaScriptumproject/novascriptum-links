## 📖 О проекте

**NovaScriptum** — это современный консалтинговый проект, ориентированный на квалифицированную помощь студентам в написании и подготовке академических работ любой сложности. 

Данный репозиторий содержит исходный код официальной посадочной страницы-визитки. Сайт разработан с акцентом на высокую скорость загрузки, премиальный визуальный стиль (соответствующий бренду) и интерактивный пользовательский опыт (UX).

---

## ✨ Ключевые фичи и UI-эффекты

* **🌓 Адаптивная экосистема тем:** Полноценная поддержка **Ночной** (по умолчанию) и **Дневной** тем. Выбор пользователя бесшовно сохраняется в `localStorage` браузера и не сбрасывается при обновлении страницы.
* **🪶 Эффект «Пера» (Particle System):** Реализована уникальная микро-анимация вылетающих частиц-перьев из логотипа при наведении или клике, подчеркивающая тематику академического письма.
* **🌊 Интерактивные Ripple-волны:** При нажатии на любую кнопку-плашку от места клика расходится мягкая полупрозрачная волна (эффект Material Design).
* **🔮 Брендированное неоновое свечение:** Каждая кнопка при наведении плавно окрашивается в фирменный цвет соответствующей соцсети или мессенджера (Telegram, VK, WhatsApp, Instagram) с добавлением мягкого свечения (box-shadow).
* **📨 Интеллектуальный Email-шаблон:** Ссылка на почту открывает почтовый клиент с уже предзаполненной структурой заказа (тема, сроки, выбор типа работы: курсовая, диплом, реферат, эссе, презентация).
* **📱 Мобильный Full-Responsive:** Интерфейс идеально перестраивается и выглядит монолитно как на FullHD мониторах, так и на ультра-малых смартфонах (до 375px).

## 🛠️ Стек технологий

Проект реализован на чистом стеке (**Vanilla**) без использования тяжеловесных фреймворков, что гарантирует максимальную оценку производительности в Google Lighthouse:

| Технология | Назначение в проекте |
| :--- | :--- |
| **HTML5** | Семантическая разметка, интеграция шрифтов *Geologica* & *Montserrat* и иконок *FontAwesome v6.4.0*. |
| **CSS3** | Продвинутая анимация (`@keyframes`), кастомные свойства (`:root`), размытие заднего плана (`backdrop-filter`) и темизация. |
| **Vanilla JS** | Логика переключения тем, обработка Web Animations API для генерации частиц и Ripple-эффекта. |
