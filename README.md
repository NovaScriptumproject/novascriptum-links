## Что это

Репозиторий официального сайта **NovaScriptum** — сервиса информационно-аналитических и консультационных услуг.

Здесь нет ни одного фреймворка и ни одной сборки: только `HTML`, `CSS` и чистый `JavaScript` — около 85 КБ кода. Открывается за доли секунды и одинаково хорошо выглядит на телефоне и на большом мониторе.

Раньше это была страница-визитка с кнопками-ссылками. Теперь — **витрина с тарифами**: человек видит цену сразу, собирает заказ в корзину и уходит оформлять его в Telegram-бот, не переписываясь с менеджером ради вопроса «а сколько стоит?».

## Что внутри

| | |
| :--- | :--- |
| 🪟 **Витрина тарифов** | Четыре карточки услуг с ценами и объёмами. Никаких «уточняйте в личных сообщениях». |
| 🛒 **Корзина** | Выбор нескольких работ, подсчёт суммы, количество слайдов, передача заказа в бот. |
| 🌓 **Две темы** | Ночная по умолчанию, дневная по кнопке. Выбор запоминается в `localStorage`. |
| 📱 **Адаптив** | Три контрольные точки — 960, 768 и 480 px. Витрина не рассыпается на телефоне. |
| ✨ **Микроанимации** | Частицы-перья из логотипа, ripple-волны от клика, мягкое свечение кнопок. |
| ⚖️ **Оферта** | Полный юридический текст — в оформленной HTML-версии и в исходном `.txt`. |
| 🚀 **Ноль зависимостей** | Ни npm, ни сборщиков, ни CDN-фреймворков. Открыл файл — сайт работает. |

## Тарифы

| Услуга | Объём | Стоимость |
| :--- | :--- | ---: |
| Реферат | 12–15 листов | **450 ₽** |
| Доклад / Эссе | 5–7 листов | **350 ₽** |
| Презентация | 7 слайдов | **250 ₽** |
| — дополнительный блок | каждые +5 слайдов | +50 ₽ |
| Курсовая | обсуждается | рассчитывается индивидуально |
| Диплом | три этапа | рассчитывается индивидуально |

Оплата — через Telegram-бота `@novascriptum_pay_bot`, платёж обрабатывает **Platega.io**. Бот не выставляет счёт больше 10 000 ₽ за один платёж — крупные работы идут этапами.

## Стек

```
HTML5    семантика, инлайновые SVG
CSS3     кастомные свойства, темы, @keyframes, backdrop-filter
JS       темы, корзина, частицы, IntersectionObserver
```

Шрифты — **Cormorant Garamond** для заголовков и **Inter** для текста. Только два запроса к Google Fonts, остальное — локальные файлы.

## Запуск

Скачай папку и открой `index.html` — этого достаточно. Локальный сервер не нужен, но если хочется:

```bash
python -m http.server 8000
# затем http://localhost:8000
```
